# Domar: Two-Player Console Snake

## Overview
Domar is a local two-player console-based adaptation of the classic Snake game. Instead of a solo survival experience, players compete against each other in a shared terminal arena. The game features various in-game entities that add strategic depth and challenge to the traditional snake mechanics.

## Features
*   **Local Multiplayer:** Two players can play simultaneously on the same keyboard in a shared console grid.
*   **Dynamic Entities:** Navigate around custom entities (such as obstacles, varied food types, or power-ups) that alter game-play dynamics.
*   **Console Interface:** Lightweight, terminal-based rendering for a responsive, retro arcade feel.
*   **Competitive Gameplay:** Outmaneuver your opponent, avoid collisions with walls and tails, and grow to become the longest snake.

## Controls
*   **Player 1:** `W`, `A`, `S`, `D`
*   **Player 2:** `Up`, `Down`, `Left`, `Right` Arrow Keys

## Game-play Mechanics
*  **Mouse:** Consume mouse entities to grow your snake and increase your score.
*  **Golden Star:** Consume golden stars to boost your speed.
*  **Poison:** Consume poison to become smaller and lose score.
*  **Bernard Clock:** Consume Bernard clock to freeze your opponent.
*  **Game Over:** Colliding with the arena boundaries, your own body, or the opponent's body results in a loss.
